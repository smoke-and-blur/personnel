# Облік особового складу

Go-бекенд + один HTML + MongoDB Atlas. Штатки (посади) + люди + допуски + відсутність + журнал.

## Модель
- `posts` — штатні посади (`sheet` — назва штатки, підрозділ, назва, мітка `tag`).
  Створюються імпортом, назви/мітки далі не редагуються.
- `persons` — люди. `postId` заповнене = штатний (посада/мітка з posts), порожнє = позаштатний
  (посада — вільний текст). Усередині — `certs` (допуски) і `absences` (відсутність).
- `journal` — лог усіх дій, переживає видалення записів.

## Дві незалежні осі
- **Штатка** (`sheet`) — окремий перелік посад: бойові, охорона кордону тощо.
  Їх може бути скільки завгодно, звіт і підсумок рахуються за кожною окремо.
- **Штат** (`tag`) — напрям усередині штатки: МРТ, РЕБ, FPV…

Перемикач «Штатка» стоїть над таблицею і показується завжди — навіть коли штатка одна,
щоб було видно, що їх може бути кілька. Нова штатка створюється імпортом: у діалозі
є поле «штатка» або колонка «Штатка» у файлі.

Пункт **«Разом (усі штатки)»** — тоді зліва додається злитий
стовпчик **«Тип підрозділу»** (штатка), а за ним звичний стовпчик «Підрозділ»;
у звіті в цьому режимі зʼявляються підсумки по кожній штатці окремо плюс «Разом усі».
Якщо штатка одна — перемикач ховається.

Перемикач «Штат» задає, відносно якого напряму рахується штат. Штатний — той, хто сидить
на посаді цього напряму; усі решта (зокрема штатні інших напрямів) для нього позаштатні.
Тому штатний РЕБ у режимі «МРТ» показується як позаштатний — і навпаки.

Позаштатні кріпляться до **підрозділу**, а не до штатки: у звіті людину зараховано до тієї
штатки, у якій є посади її підрозділу (двічі вона не рахується).

## Імпорт
«Дії → Імпорт таблиці». Вставляєш діапазон з Excel (Ctrl+V) або вибираєш файл CSV/TSV, далі
зіставляєш колонки — порядок і склад довільні, зайві колонки ігноруються.
Роздільник (TAB `;` `,` `|`) і заголовок визначаються автоматично, їх можна перевизначити.

Повний формат (`sample_import.tsv`):
```
Штатка	Підрозділ	Посада	Штат	в/з	ПІБ
Бойові	1 взвод	начальник відділення	МРТ	штаб-сержант	ІВАНЕНКО Іван Іванович
```
- **Штат** — це мітка посади. **Порожній «Штат» = позаштатний**: посада в штатці не створюється,
  людина йде у склад як позаштатна з посадою вільним текстом.
- Рядок без ПІБ — просто вакантна посада у штатці.
- Порожні «Штатка» і «Підрозділ» успадковуються з рядка вище (обʼєднані клітинки Excel);
  можна вимкнути. Якщо колонки «Штатка» немає — діє поле «штатка» над таблицею.
- Стара штатка з трьох колонок (`підрозділ;посада;мітка`, `sample_shtatka.csv`) імпортується так само.

Скільки однакових трійок (штатка+підрозділ+посада) у файлі — стільки й слотів, тож пʼять
«операторів FPV» дадуть пʼять посад, а однойменна посада у двох штатках лишиться двома різними.
Наявні посади перевикористовуються, людей звіряємо за ПІБ, тому повторний імпорт того самого
файлу нічого не дублює. Наявним посадам без мітки мітка з файлу проставляється.

## Інтерфейс
Вкладки: **Склад** (штатні і позаштатні в одній сітці), **Звіт**, **Вибулі**, **Журнал**.

Підрозділ — злитий стовпчик зліва (один на групу: штатка + підрозділ, з лічильником
`укомплектовано/посад`).

**Фільтри — на заголовках колонок.** Клік по назві колонки відкриває перелік значень
з лічильниками (Підрозділ, Штат, в/з, Наявність, Головний допуск) або поле «містить»
(Посада, ПІБ). Активний фільтр підсвічує заголовок. Плюс загальний пошук і «Скинути фільтри».

**Звання — знаком розрізнення.** Колонка «в/з» стоїть перед ПІБ і показує квадратну
іконку 20×20, повна назва — у миттєвій підказці. Рядовий і сержантський склад — за чинною
схемою ЗСУ: кокарда з OR-2, далі кути 1…5 (старший солдат → головний сержант),
у групі OR-9 (штаб/майстер-сержанти) кути над дугою; рекрут — без знаків. Клік по клітинці
відкриває список звань. У солдата знаків немає — клітинка порожня; нерозпізнане звання
показується текстом як є. Малюнок **умовний**: будується з таблиці `RANKS` на початку
`index.html` — щоб підігнати під реальні погони, правити треба лише її.

**Кольори.** Рядок отримує стриманий відтінок за власною міткою — МРТ синюватий,
РЕБ червонуватий (`HUE` в `index.html`). Обраний напрям додатково має смужку зліва
й трохи щільніший фон. Позаштатні лишаються нейтральними, колонка «Штат» у них порожня.
Типово обрано напрям **МРТ**.

**Відсутність.** У розгортці рядка поруч із допусками — записи `хв / вдр / вдп / інше`
з полями «з», «по», місце, примітка. Чинна сьогодні відсутність показується чіпом
у колонці «Наявність», рядок притлумлюється, а людина виходить із «в наявності».

- Вакансія заповнюється прямо в рядку (ПІБ + звання) — людина створюється, щойно залишаєш рядок.
- Переміщення/призначення — одна модалка зі **всіма** посадами, не лише вакантними;
  біля кожної видно, вакансія це чи хто на ній. Якщо посада зайнята, модалка питає,
  куди подіти нинішнього: **поміняти місцями** (він піде на посаду того, кого переміщуємо)
  або **у позаштат**. Обмін недоступний, якщо той, кого призначають, позаштатний.
- Позаштатного додає кнопка «Позаштатний»; його підрозділ міняється іконкою олівця в рядку.
- При вибутті посада стає вакантною, запис лишається у «Вибулих»; остаточне видалення тільки звідти.
- Кнопки дій зʼявляються при наведенні на рядок; `/` — фокус у пошук.
- Таблиця типово **лише для читання**: клік по будь-якій клітинці виділяє рядок.
  Щоб правити ПІБ, звання чи посаду інлайн — кнопка «Редагування» (стан запамʼятовується).
- Виділення знімається кліком повз таблицю, клавішею `Esc` або кнопкою «Зняти».

**Виділення рядків.** Клік по рядку (по клітинці, а не по полю вводу) виділяє його,
затиснути й потягнути — виділити підряд, `Shift` — діапазон від попереднього,
`Ctrl`/`Cmd` — додати або зняти окремий, `Ctrl+A` — усі показані, `Esc` — зняти.
Клік по клітинці підрозділу або типу підрозділу бере всю групу.
Знизу зʼявляється панель із діями над виділеним:

- **Копіювати** — рядки у буфер як TSV (вставляється просто в Excel);
- **Експорт** — тільки виділене окремим файлом XLSX;
- **Відмінок…** — просклоняти ПІБ обраних у потрібному відмінку.
- «Дії → Скинути дані» — вибіркове очищення (штатки / люди / журнал), підтвердження словом `СКИНУТИ`.
  Якщо видалити лише штатки, люди не зникають, а переходять у позаштатні.

## Відмінювання ПІБ
Кнопка «Відмінок…» над виділенням будує список у потрібному відмінку (родовий,
давальний, знахідний, орудний, місцевий, кличний) — для наказів і подань:

```
штаб-сержанта ІВАНЕНКА Івана Івановича
старшого сержанта ПЕТРЕНКА Петра Петровича
```
Опції: зі званням чи без, повне ПІБ або «Прізвище І. П.», нумерація.
Стать визначається за по батькові (`-ович` / `-івна`), звання відмінюється разом з ПІБ.

Правила покривають типові українські закінчення: прикметникові прізвища (`-ський`, `-ий`),
`-енко`/`-ко`, випадне *е* (`Кравець → Кравця`, `Заєць → Зайця`), чергування `г/к/х → з/ц/с`
у давальному (`Ольга → Ользі`), жіночі прізвища на приголосний і на `-о` не відмінюються.
**Це евристика** — рідкісні та іншомовні прізвища можуть відмінитись неточно, тому текст
у діалозі редагується перед копіюванням. Правила зібрані в одному місці `index.html`
(`declLast`, `declFirst`, `declMid`, `declRank`).

## Телефон
Ширше 720 px — повна таблиця. Вужче вмикається окрема розкладка на три колонки без
бічної прокрутки: **підрозділ** (злитий, з назвою штатки й лічильником), **ПІБ** зі знаком
розрізнення і посадою дрібним рядком під ним, **дії**. Напрям і відсутність не займають
окремих колонок — їх видно за кольором рядка та підписом біля посади.
Перемикач штатки розтягується на всю ширину, напрями гортаються стрічкою,
підсумок стискається в один рядок.

## Звіт і підсумок
Смужка над таблицею — підсумок за поточним вибором (штатка + напрям). Вкладка «Звіт» — та сама
арифметика в розрізі підрозділів, з рядком «Разом» і вивантаженням у XLSX:

| Підрозділ | За штатом | Штатних | Вакансій | Позаштатних | За списком | Відсутніх | В наявності | Укомплектованість |

- **за штатом** — посад у штатці (за обраним напрямом);
- **штатних** — з них зайнятих; **вакансій** — решта;
- **позаштатних** — активні без посади в цьому підрозділі;
- **за списком** = штатних + позаштатних;
- **відсутніх** — у кого чинна відсутність на сьогодні;
- **в наявності** = за списком − відсутніх;
- **укомплектованість** = штатних / за штатом.

Експорт XLSX (у меню «Дії») — аркуші Штатка, Позаштатні, Допуски, Відсутність, Звіт, Журнал.

## Запуск / деплой
```bash
export MONGODB_URI="mongodb+srv://..."
export API_KEY="свій-ключ"   # інакше — захардкожений у main.go
go mod tidy && go run .      # http://localhost:8080
DEV=1 go run .               # статика з диска — правки в index.html видно одразу
go test ./...                # планування слотів імпорту, розбір ключів
```

> **Не бачите змін в інтерфейсі?** `//go:embed static` вшиває `static/index.html`
> у бінарник під час компіляції. Уже запущений процес віддає стару сторінку —
> треба перезапустити `go run .` (або перезібрати бінарник), а на Render запушити
> й передеплоїти. Під час розробки зручніше `DEV=1 go run .`: статика читається
> з диска, перезапуск не потрібен.

Render: репозиторій + render.yaml, env `MONGODB_URI`, `API_KEY`. Atlas: Network Access 0.0.0.0/0.

## Логіка головного допуску
Вага = базова вага мітки + рівень (`CERT_BASE`, `LEVEL_LABELS`, відтінки напрямів — `HUE`,
види відсутності — `ABSENCE`, звання — `RANKS`; усе на початку `index.html`).
Перехоплювачі > FPV р.2 (оптика) > FPV р.1 > Бомбер > Крило > МРТ > РЕБ > Сапер.
Спершу профільні (мітка серта = мітці посади), інакше — найважчий загалом.
